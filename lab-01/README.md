# StudyOrbit — лабораторна/практична робота 1

Невеликий застосунок: заставка → головний екран → діалог «Про застосунок».
Стек: HTML + CSS + JavaScript, без залежностей. Логотип — `logo.svg` (векторний).

## Запуск
Відкрийте `index.html` у браузері, або:

    python -m http.server 8000   # потім http://localhost:8000

## Тема
Світла / темна / авто (за системою). Вибір зберігається в localStorage.

## Файли
- `index.html` — застосунок
- `logo.svg`, `logo-dark.svg`, `logo-mono.svg` — логотип (основний, для темного фону, монохромний)
