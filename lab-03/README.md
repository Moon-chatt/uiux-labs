# Практична робота 3 — Структура взаємодії UI (StudyOrbit)

**Виконав:** Ляшенко К. В., група 621п · 2026

Інформаційна архітектура та структура взаємодії планувальника навчання **StudyOrbit**.

## Склад теки

| Файл | Що це |
| --- | --- |
| `index.html` | Сторінка зі світлою/темною темою: sitemap, навігаційна модель, user flows, матриця станів, аналіз кліків, error/empty states |
| `structure.pdf` | Ті самі матеріали одним PDF-файлом |
| `logo.svg` | Логотип StudyOrbit |

## Зміст
- **База:** карта екранів (Sitemap), 3 User Flows (додати дедлайн, фокус-сесія, перенесення прострочених), навігаційна модель (вкладкова з хабом «Сьогодні»).
- **Просунутий рівень:** матриця переходів станів, аналіз правила трьох кліків, сценарії помилок і порожніх станів.
