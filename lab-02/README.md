# Практична робота 2 — Розробка персонажів (StudyOrbit)

**Дисципліна:** UI/UX дизайн · НАУ «ХАІ», кафедра інженерії ПЗ (603)
**Виконав:** Ляшенко К. В., група 621п · 2026

Персони, карта емпатії та супутні артефакти для **StudyOrbit** — вебзастосунку-планувальника навчання студента (логотип і застосунок — у `lab-01`).

## Склад теки

| Файл | Що це |
| --- | --- |
| `index.html` | Сторінка в стилі StudyOrbit зі світлою/темною темою: усі артефакти в одному місці |
| `personas.pdf` | Усі картки одним файлом (по дві на сторінці) |
| `interview.md` | Нотатки верифікаційного інтерв'ю (анонімно) |
| `logo.svg` | Логотип StudyOrbit |

## Як переглянути
Завантажте теку та відкрийте `index.html` у браузері. Тему можна перемкнути кнопками «Світла / Темна / Авто».

## Рівні завдання
- **База:** 3 персони, карта емпатії.
- **Просунутий:** антиперсона, User Journey Map, верифікаційне інтерв'ю.
