Репозиторій з практичними роботами з дисципліни «UI/UX дизайн» (НАУ «ХАІ», кафедра інженерії програмного забезпечення, 603).

**Автор:** Ляшенко К. В., група 621п · 2026

## Як переглянути
У кожній теці є `index.html` (для lab-01 це сам застосунок): завантажте теку й відкрийте файл у браузері. Сторінки підтримують світлу та темну тему.
