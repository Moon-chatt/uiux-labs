# Практична робота 4 — Компонування елементів UI (StudyOrbit)

**Дисципліна:** UI/UX дизайн · НАУ «ХАІ», кафедра інженерії ПЗ (603)
**Виконав:** Ляшенко К. В., група 621п · 2026

Lo-Fi вайрфрейми та компонування інтерфейсу планувальника навчання **StudyOrbit**.

## Склад теки

| Файл | Що це |
| --- | --- |
| `index.html` | Сторінка зі світлою/темною темою: 8pt сітка, вайрфрейми 1440 px і 390 px, гештальт, клікабельний прототип, F/Z-патерни |
| `layout.pdf` | Ті самі матеріали одним PDF-файлом |
| `logo.svg` | Логотип StudyOrbit |

## Зміст
- **База:** 4 екрани (головний, список, детальна картка, форма), 8pt сітка та 12-колонкова розмітка, гештальт-принципи.
- **Просунутий рівень:** мобільна версія 390 px, клікабельний прототип, аналіз за F- та Z-патернами.

## Як переглянути
Відкрийте `index.html` у браузері. Перемикачі «Сітка 8pt» та «12 колонок» вмикають накладення сітки на вайрфрейми, а в розділі 5 можна клікати по прототипу.
